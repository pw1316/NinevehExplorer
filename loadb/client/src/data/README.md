# 数据存储规则

- 文件名为 `<table_name>.csv` 是格式为**CSV**的文件，`<table_name>`为数据表的名字
  - **数据表名**允许范围：小写字母，数字，下划线。且不能用数字开头
- 第一行为表头，每一列表示**列名**
- 第二行为表头，每一列表示这一列的**数据类型**。支持以下几种：
  - ul: 数字**无符号64位整数**
  - il: 数字**有符号64位整数**
  - u: 数字**无符号32位整数**
  - i: 数字**有符号32位整数**
  - d: 数字**双精度浮点**
  - f: 数字**单精度浮点**
  - s：**字符串**
- 从第三行开始，每一行代表一条**数据行**
- 每条**数据行**的第一列是**主键**，用于在表中索引这一行
  - **主键**必须唯一
  - **主键**的**数据类型**只能是ul或s
    - 如果类型是ul：必须是一个十进制下的11位数，**前2位**表示**表名ID**，需要和`<table_name>`形成一一对应，不同表不能用相同的**表名ID**，同一表内不能使用不同的**表名ID**；**随后4位**表示数据表内分组；**最后5位**表示组内ID
